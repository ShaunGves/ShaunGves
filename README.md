## 🔥 Featured Builds

### 🧠 SmartRAG — Production-Grade RAG AI Coding Assistant
> Fine-tuned **Mistral-7B (QLoRA)** + hybrid retrieval (**BM25 + dense embeddings via ChromaDB**) + **cross-encoder reranking** + a **ReAct agent**, served through a FastAPI backend and React frontend, with full Docker/CI-CD infra.

![Mistral-7B](https://img.shields.io/badge/-Mistral--7B-FF6B00?style=flat-square)
![QLoRA](https://img.shields.io/badge/-QLoRA-9C27B0?style=flat-square)

### 🏠 PropChain — Tokenized Real Estate dApp
> Full-stack Web3 platform with 3 Solidity contracts (`PropertyFactory`, `PropertyEscrow`, `PropertyToken`) enabling **fractional real estate investment via ERC-20 tokens** on Ethereum Sepolia. Trustless escrow with automated fund distribution and reentrancy-safe Checks-Effects-Interactions design. React + MetaMask + Alchemy RPC frontend, live on-chain.

![Solidity](https://img.shields.io/badge/-Solidity-363636?style=flat-square)
![Hardhat](https://img.shields.io/badge/-Hardhat-FFF100?style=flat-square)

![ERC--20](https://img.shields.io/badge/-ERC--20-3C3C3D?style=flat-square)

### 🧬 Quantum-Classical Hybrid Network for Autism Detection
> Quanvolutional Neural Network (**QNN**) built with **PennyLane**, encoding facial image patches into **4-qubit quantum circuits** in place of classical CNN filters. End-to-end hybrid pipeline over 2,940 facial images, benchmarked against a classical baseline using TensorFlow/Keras + Adam optimization.

![PennyLane](https://img.shields.io/badge/-PennyLane-00B5AD?style=flat-square)
![Quanvolution](https://img.shields.io/badge/-Quanvolution-7209B7?style=flat-square)
![TensorFlow](https://img.shields.io/badge/-TensorFlow-FF6F00?style=flat-square)

### 🎬 VidIntel Studio — AI Video Intelligence Tool
> Full-stack tool converting long-form video into structured notes and action items using the **Claude API**, with a React frontend and a planned production pipeline (yt-dlp, Whisper, ChromaDB).
